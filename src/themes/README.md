Color palettes adapted from [Kiranism/next-shadcn-dashboard-starter](https://github.com/Kiranism/next-shadcn-dashboard-starter/tree/main/src/styles/themes), under the included MIT license.

Claude, Discord, Supabase, Vercel, and Astro Vista use the supplied reference files. Mono, Notebook, Light Green, Zen, and WhatsApp use the upstream files. Palette variables are mapped to this app's tokens; Next.js-specific font variables and global Tailwind theme declarations are omitted. Fonts fall back to locally available families.

The Default option uses the existing application styles without a palette override. Light/dark mode is independent of the selected palette.
